## 🤖 Featured Project

### AI Log Analysis Agent

<a href="https://github.com/Hasanulgit/AI-Log-Agent">
<img src="https://img.shields.io/badge/View_Project-AI--Log--Agent-181717?&style=for-the-badge&logo=github&logoColor=white" />
</a>

An AI-powered cybersecurity log analysis agent built with **Python and OpenAI**.

The project ingests security logs, removes common sensitive credentials, and uses an LLM to identify suspicious activity and produce structured security findings.

### Current capabilities

- Reads and bounds security log data before analysis
- Redacts common passwords, API keys, tokens, secrets, and authorization headers
- Uses an LLM to analyze suspicious activity
- Classifies event severity and event type
- Extracts security indicators
- Generates recommended investigative actions
- Handles configuration and API failures
- Includes automated tests with mocked API calls

**Current development:** Continuous log monitoring and event batching.
